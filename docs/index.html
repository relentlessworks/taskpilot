TaskPilot v0.1.0

Agentic-first task manager. The agent IS the interface.

TaskPilot is a task management service designed for AI agents to drive over plain HTTP. No UI, no SDK. The API is the product.

Quick Start

make build
./taskpilot

API

POST   /auth/request        email=me@example.com&workspace=ws_demo
POST   /auth/verify          email=me@example.com&code=123456
POST   /api/tasks            title=Fix bug&priority=high
GET    /api/tasks            [?status=todo|in_progress|done]
GET    /api/tasks/
PATCH  /api/tasks/   status=done
DELETE /api/tasks/
GET    /api/workspace
GET    /help
